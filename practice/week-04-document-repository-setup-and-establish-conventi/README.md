## Task Brief
Set up repository structure, document setup procedures, create branching conventions, and establish commit message standards for the capstone project.

Your team needs clear documentation on how to set up the project locally and follow consistent Git conventions. Document procedures and establish standards.

- CONTRIBUTING.md with branching and commit conventions

## Success Criteria
- Setup instructions are clear and tested
- Branching convention is documented and followed
