# Create Well-Structured Commits with Meaningful Messages

## Task Brief
Practice creating commits with clear, descriptive messages following conventions. Add features to capstone while maintaining clean commit history.

## Scenario
Add a new utility function to your Python project with well-structured commits. Each commit should have a clear message explaining the change and its purpose.

## Deliverables
- Feature branch with 3+ commits
- Commits with descriptive messages

## Success Criteria
- Each commit message follows the established format
- Commit messages clearly describe the change
