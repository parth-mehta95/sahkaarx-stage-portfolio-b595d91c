# Resolve Merge Conflicts in Capstone

## Task Brief
Intentionally create conflicting changes on two branches, manually resolve conflicts, and merge back to main with clean commit history.

## Scenario
Two team members edited the same file. Simulate this conflict, resolve it manually, and merge both changes correctly.

## Deliverables
- Two branches with conflicting edits
- Resolved conflict markers in code

## Success Criteria
- Conflict markers correctly identified and removed
- Both sets of changes integrated logically
