# Advanced Multi-Branch Conflict Resolution in Capstone

## Task Brief
Create 3+ feature branches with intentional conflicts, resolve using rebase and merge strategies, and document resolution patterns.

## Scenario
Your team is working on parallel features. Simulate realistic conflicts across multiple branches and resolve them systematically.

## Deliverables
- 3+ feature branches with conflicting edits
- Resolved conflicts with clean commit history

## Success Criteria
- All conflicts resolved without markers
- Main branch merges cleanly
