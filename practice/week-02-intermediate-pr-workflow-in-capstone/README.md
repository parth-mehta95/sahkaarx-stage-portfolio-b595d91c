# Intermediate PR Workflow in Capstone

## Task Brief
Create feature branch with conflicting changes, request code review, and merge using intermediate PR techniques on your capstone repo.

## Scenario
Your team needs a feature branch with code review feedback loop. Create a PR, address comments, and merge cleanly.

## Deliverables
- Feature branch with 2+ commits
- PR with review feedback resolved

## Success Criteria
- PR shows meaningful code review comments
- All feedback addressed before merge
